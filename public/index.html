Proyectos

Una selección de proyectos académicos, de servicio social y personales.

Motor de búsqueda semántica de datos abiertos

Página web con búsqueda semántica para el catálogo de datos abiertos del gobierno municipal de León, Guanajuato. Permite encontrar datasets con consultas en lenguaje coloquial.

Tecnologías usadas

  • Python y FastAPI
  • ChromaDB y Sentence Transformers
  • JavaScript vanilla
  • Docker y Azure Container Apps

YUMANA — Sistema de gestión de personas usuarias

Proyecto de servicio social. Plataforma web que reemplaza el seguimiento en hojas de cálculo, con control de acceso por roles y niveles de confidencialidad. Me encargo del frontend.

Tecnologías usadas

  • React, TypeScript y Vite
  • Tailwind CSS y HeroUI
  • Diseño de interfaces en Figma

Detección de fallas en fresadoras con Random Forest

Modelo de machine learning para detectar fallas en fresadoras, con 75% de recall sobre una tasa de falla de 3.4%, usando GridSearchCV y bootstrapping de 1000 iteraciones.

Tecnologías usadas

  • Python
  • scikit-learn (Random Forest, GridSearchCV)
